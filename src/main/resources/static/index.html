RETRIEVAL QUALITY

命中率：有参考文件命中的问题占比；Recall@K：命中的参考文件占比；MRR：首个正确切片排名的倒数。应无结果的问题单独计入空结果准确率。阈值为 0 时，向量检索通常仍会返回最近邻。
